# 하이브레인 과거 후보 65건에서 확보한 수집 경로 검증

검증일: 2026-10-30. 운영 DB·개인 운영 설정은 변경하지 않았으며 기존 작업은 보존했다.

아래는 최초 12개 추가 당시의 기록이다. 이후 미확정 대상을 조사해 2개 게시판을 더 추가했고,
현재 보완 배치는 기존 4개 + 신규 14개 = 18개다. 후속 검증은 마지막 절에 기록했다.

## 범위와 결과

- 기존 기간 미확정 후보 65건은 이전 상세 기록 43건과 추가 확인 22건을 대조하면
  최초 등록일이 모두 2026-09-15~09-28이다. 월간 기준 09-29~10-29의 수집 실패 65건이 아니다.
- 과거 공고는 향후 새 공고가 올라올 게시판·검색·페이지 이동 경로를 찾는 표본으로 사용한다.
- 신규 기관 9곳과 기존 기관의 별도 게시판 3곳을
  [기존 하이브레인 보완 배치](../config/batch-hibrain-recovery.example.toml)에 추가했다.
  기존 경로 4곳을 유지해 활성 소스는 16개다.
- 신규 12곳 + 기존 5곳 = 17개 프로파일을 실제 수집기로 검증했다.
  최종 HTTP 요청은 총 65회이며 TLS 검증 해제나 접근 제한 우회는 없었다.
- 신규 12곳 모두 표본을 확보했다. 11곳은 기존 65건의 원문 표본,
  강남구는 현재 목록에 있는 10/30 신규 모집 공고로 검증했다.
  과거 65건을 모두 다시 수집했다는 의미가 아니다.

## 검색·등록일·페이지 처리

- 공식 GET/POST 검색과 페이지 조건을 사용한다. 과거 표본의 날짜·게시물 번호를 목록 URL에 고정하지 않았다.
- 영암군은 영문·숫자 ID와 상세의 전체 제목을 사용한다.
- 전남TP의 포트 443 링크는 게시물 번호로 공식 상세 주소를 구성해 정규화한다.
- 경남관광재단의 인코딩된 bbsData는 사이트 링크 그대로 보존하고 검색·페이지 조건만 제거한다.
  임의로 ID를 추측하거나 JavaScript를 실행하지 않는다.
- 경북RISE센터와 강원교육청은 클릭 속성의 게시물 번호를 읽는다.
- 부산TP 목록의 만료일을 등록일로 쓰지 않고 상세의 명시적인 작성일을 사용한다.
- 경남관광재단·경북RISE센터는 총건수와 페이지 번호를 검증하고 마지막 페이지에서 종료한다.
  경북RISE센터의 빈 페이지는 현재 페이지가 0이고 목록 하위 컨테이너가 사라질 수 있다.
- 강남구의 “고시공고 결과가 없습니다.”를 명시적인 빈 목록으로 인식하도록 공통 HTML 파서를 보완했다.
  유효 링크가 함께 있으면 빈 목록으로 무시하지 않는다.

강남구 과거 원문 65236은 이번 응답에서 본문이 확인되지 않았고 검색 목록에도 없었다.
목록에는 게시기간이 지난 게시물의 자동 삭제 안내가 있다.
경로 검증에는 현재 모집 공고 65756을 사용했다.
같은 날 평가결과 공고 65761을 과거 모집 공고와 같은 게시물로 세지 않았다.

## 검증

- 전체 자동화 테스트: **2148 passed**.
- 변경 Python 파일 Ruff 검사와 git diff --check 통과.
- 신규 12개 게시판 표본 수집: **12/12 성공**.
- 최종 17개 프로파일의 표본·최신 구간 조회에서 예외 없음.
- 최신 구간 총 7건: 신규 경로 3건, 기존 5개 경로 4건.
  신규 경로의 강남구·영암군 평가결과 2건이 포함된다.
- 과거 표본과 최신 구간을 합친 고유 18건을 별도 검증 DB에 저장하고
  기관·제목·등록일·URL을 조회 대조했다. 동일 데이터 재저장 후에도 **18 → 18건**이었다.
  이는 DB 재저장 검증이며 두 번의 독립 네트워크 수집을 뜻하지 않는다.
- 실제 응답·진단 실행기·검증 DB: data/live-tests/routes65-20261030/ (Git 제외).
- 개인정보를 제거한 표본 16건은 tests/fixtures/hibrain_routes_profiles.json에 모아
  기존 공통 단위·CLI 통합 테스트에 연결했다. 테스트 파일은 새로 분리하지 않았다.
- 임시 폴더 권한 오류가 난 초기 샌드박스 실행은 통과 결과에서 제외했다.
  최종 전체 테스트는 정상 권한으로 완료했다.

## 후속: 미확정 대상에서 발견한 공개 게시판 2개 추가

기존 16개 소스의 설정은 보존하고 같은 보완 배치에 아래 경로를 활성화했다.

| 소스 | 게시판 | 실제 수집 표본 | 게시일 |
|---|---|---|---|
| dtmsa_bid | 대구전통시장진흥재단 사업공고 | [상인연합회 전통시장 소비 촉진 행사 평가위원 모집](https://www.dtmsa.or.kr/board/bid/1005) | 2026-09-23 |
| esk_recruit | 대한인간공학회 채용 및 공고 | [안전보건공단 공공기관 안전활동 수준평가 공모](https://esk.or.kr/recruit/68) | 2026-10-02 |

- 대구 사업공고는 기존 재단 공지사항·입찰공고와 다른 게시판이다. 기존 두 경로를 대체하지 않았다.
- 재단 공식 폼대로 POST, searchKey=ARTICLE_TITLE, searchword 검색과 page 이동을 사용한다.
  잘린 목록 제목은 상세의 전체 제목으로 보완하고 상세 작성일을 사용한다.
- 대한인간공학회는 공개 GET 제목 검색과 page 이동을 사용한다.
  마지막 페이지의 안내 문구 없는 단일 empty_table 셀만 제외한다.
  같은 셀에 실제 링크가 있으면 빈 결과로 숨기지 않고 정상 행 검증을 거친다.
- 두 경로 모두 recruitment_only=false, TLS 검증 유지, 런타임 fixture 없음이다.
  표본 게시물 번호와 과거 날짜는 운영 목록 URL에 고정하지 않았다.
- 재게시 기관명과 해당 게시판의 등록일·URL을 보존한다.
  학회 표본은 기존 한국가스학회에서도 확보한 같은 사업이므로 새 누락 공고 2건 해결로 집계하지 않는다.
- 이 두 경로는 65건의 최초 경로 발굴 뒤 진행한 후속 조사 결과다. 최초 월간 대조율을 다시 계산하지 않았다.

### 후속 검증 결과

- 최종 설정으로 두 경로 모두 실제 수집기에서 표본의 제목·등록일·URL 수집 성공.

- 실제 CLI collect를 2026-09-23~10-02 구간으로 독립적으로 두 번 실행했다.
  매 실행 HTTP 요청 6회로 표본 2건을 수집했고, 격리 DB는 2 → 2건으로 유지됐다.
  두 번째 실행도 실제 네트워크 요청을 했으며 운영 DB에는 저장하지 않았다.

- 표본 두 건을 기존 hibrain_routes_profiles.json에 합쳐 총 18개 회귀 표본으로 사용한다.
