# 하이브레인 최근 1개월 1차 경로 확장 검증

검증일 2026-10-29. 기준 기간은 **2026-09-29~2026-10-29**, 하이브레인 최초 등록일 기준이다.

## 범위와 결과

- 진행 중·마감 목록의 상세 후보 304건을 조사했다. 기간 내 등록일이 확인된 평가위원 공고는 **226건**(진행 중 72, 마감 154), 원기관 호스트는 www 접두사를 정리한 기준 **133개**다.
- 상세 34건은 HTTP 403으로 최초 등록일을 확인하지 못했다. 주로 마감 목록의 오래된 경계 구간이지만 전부 기간 밖이라고 단정하지 않았다. 나머지 44건은 확인된 기간 밖이다.
- 기존 경로 112개와 마포·양천 고시공고, 합천, 거제고현 별도 경로를 진단했다.
- **공식 게시판 26개 추가**, **안산 게시일 추출 오류 수정**. 신규·수정 대표 표본 **27/27**을 실제 CLI로 저장했다.
- 별도 검증 DB에는 관련 공고 **53건**, 두 번 전체 실행 후 **53→53**으로 중복 방지를 확인했다.
- 두 번째 실행에서 성남 재단의 비정상적인 빈 본문 응답이 발생했다. 개별 수집·재시도 성공도 확인했지만 반복 안정성은 미확인이다. 2초 간격으로도 완전히 해결되지 않았다.

**226/226 수집 완료를 의미하지 않는다.** 최초 등록일과 원기관 게시일은 다르며 현재 목록에서 빠진 과거 글도 있다. 목록 미노출을 삭제나 수집기 오류로 단정하지 않는다.

## 수정과 검증

- 안산은 상세 화면에서 사라진 작성일 선택자를 제거하고 목록 작성일을 사용한다. 상세 제목 검증은 유지한다.
- 환경산업기술원은 공식 검색 폼대로 POST로 조회한다. 익산은 `pno`를 글 번호 `no`로 읽지 않도록 쿼리 경계를 명시했다.
- 부평 센터는 전체 건수·현재 페이지로 마지막 페이지 뒤의 404 요청을 피한다.
- 울산시설공단의 서식 번호, 안성의 두 번째 함수 인자, 교육청·포천 data 속성 등은 기존 프로필로 읽는다. JavaScript 코드를 실행하지 않는다.
- 충주문화관광재단과 서울 환경 게시판은 명시적인 게시일 메타데이터를 사용한다. 수정일·월일 표기로 게시일을 추정하지 않는다.
- `등록된 내용이 없습니다.`, `등록/검색된 정보가 없습니다.`를 빈 목록 안내로 추가했다. 실제 링크, 잘못된 날짜, 비정상 HTML 검증은 유지한다.
- 고정 검색 날짜나 표본 글 번호를 운영 설정에 넣지 않았다. 고정 번호는 게시판·메뉴 식별자이며 표본 글 번호는 테스트에만 있다.

## 운영 방법

```powershell
python -m judgefinder.interfaces.cli.main --config-path config/batch-hibrain.example.toml collect --date today --days 7
python -m judgefinder.interfaces.cli.main --config-path config/batch-hibrain.example.toml list --date today --days 7
```

통합 배치는 초기 보완 4개(창원·국립해양조사원·의장협의회·섬비엔날레)와 월간 보완 26개를 합친 30개 경로다. 기관별 수집 설정은 그대로 유지했다. 노원 고시공고와 안산 수정은 기존 서울·경기 배치에 유지한다.

기존 전체 운영 설정에 `[sources.*]`와 `enabled_sources`를 함께 합쳐 사용한다. 통합 배치 기본 DB는 `data/hibrain.db`다. 기존 DB를 이어 쓰려면 `db_path`를 기존 파일로 지정한다. 기존 DB 파일은 이동·병합하지 않았으며 진단은 별도 DB에서 진행했다.

하이브레인은 원기관 발견용이며 운영 수집 소스로 추가하지 않았다. 새 경로는 recruitment_only=false이므로 결과·취소·수정 공고는 사람이 검수한다. --days는 게시일 조회 범위이며 지원 가능 여부 판정이 아니다.

## 테스트와 증거

- 통합 정리 전 전체 pytest 1,987건 통과(130.55초). 통합 후 검증 결과는 아래 최종 확인 항목에 기록한다.
- 변경 Python Ruff 통과. 전체 Ruff에는 기존 미수정 테스트의 E501 4건이 남아 있다(test_generic_engine_parser.py 3건, test_generic_engine_source.py 1건).
- 개인정보·스크립트를 제거한 초기·월간 HTML 표본은 `tests/fixtures/hibrain_profiles.json`의 34개 표본으로 통합했다. 안산은 기존 경기 표본을 재사용한다. 원래 35개 표본의 파싱 결과는 통합 전후 동일함을 확인했다. 두 파일 1,633,345바이트에서 통합 파일 94,366바이트로 줄였다.
