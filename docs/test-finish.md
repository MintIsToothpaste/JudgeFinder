# 지자체 검증 현황

최종 갱신: 2026-10-05.

전체 대상 245곳 중 **231곳은 사용자 확인 완료**, **14곳은 보류**다.
보류 지자체를 제외한 나머지는 검증 당시 수집 데이터의 제목·등록일·상세 URL 확인을 완료했다.
완료 지자체별 목록과 상세 검증 이력은 생략한다.

보류는 영구적인 수집 불가를 뜻하지 않는다. 정상 공개 경로·정확한 데이터 확보 후 재검증한다.
0건 또는 부분 수집만으로 완료 처리하지 않으며, 등록일·제목을 추정하거나 TLS 검증·열람 제한을 우회하지 않는다.

## 운영 참고

사용자 확인 완료는 검증한 게시판·기간의 데이터 기준이며 모든 게시판의 완전한 수집을 뜻하지 않는다.
운영 `config/config.toml`에는 7개 소스만 활성화되어 있다.
나머지 대상의 배치 설정 통합·활성화 또는 누락 설정 복원은 별도 작업이다.
