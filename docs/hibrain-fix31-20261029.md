# 하이브레인 비교 미확보 31건 수정·검증

검증일: 2026-10-29 / 기준 코드: `8602b02` + 이번 작업의 미커밋 변경.

아래의 ‘최초 확보 4건 / 미확정 27건’은 첫 검증 당시의 분류다. 후속 구현에서는 **재사용 가능한 공개 경로 3개를 추가해 7건을 실수집**했다. 마지막 ‘후속 구현’ 절에 경로·데이터·검증 결과를 기록했다. 재게시 자료 확보와 기관 원문 ID의 동일성 검증은 구분한다.

## 결론과 범위

- 기존 미확보 31건의 원문 응답 및 관련 수집 경로를 재검토했다. **31건 전체를 수정 완료한 것은 아니다.**
- **4건을 반복 실수집으로 확보했다.** 김해 2건은 원문 식별자가 일치하고, 속초·안동 각 1건은 원문 링크가 목록 주소여서 기관·구체적인 사업명 대조로 확인했다.
- **27건은 미확정으로 남긴다.** 이 중 제물포 3건은 기존 다른 경로에서 대체 후보를 수집하지만, 원문과 동일한 게시물이라는 증거가 부족하다. 나머지 24건도 아래와 같이 구분했다.
- 종전의 기간 미확정 후보 65건 및 후속/결과 공고 2건은 이번 31건 작업에 포함하지 않았다. 전체 월간 수집률을 새로 산출한 결과가 아니다.
- 수집 기간은 기존 비교와 같은 **2026-09-22~2026-10-29**다. 하이브레인 최초 등록일(9/29~10/29)과 기관 원문의 게시일은 다를 수 있다.
- 원문 게시 종료·삭제·검색 색인 정책 중 무엇 때문인지는 운영기관 확인 없이는 확정할 수 없다. 아래의 ‘목록 비노출’은 검증 당시 목록에서 찾지 못했다는 뜻이며 영구 수집 불가라는 뜻이 아니다.

## 수정 사항

1. 공통 HTTP 클라이언트: 기존의 시스템 인증서 신뢰 저장소 재시도와 구형 TLS 호환 재시도를 조합하는 제한된 추가 경로를 구현했다. 한 번의 호환 재시도로 해결되지 않는 속초 연결을 처리한다. HTTP에서 HTTPS로 이동한 뒤 발생한 TLS 오류도 실제 실패 요청이 HTTPS인 경우 처리한다. 인증서 검증은 유지하며 만료·호스트 불일치는 허용하지 않는다.
2. 속초 설정: 홈페이지 제목 검색의 실제 값 `TITLE`과 공개 검색폼의 POST 방식을 반영했다. 기존 `notAncmtSj`는 실제 선택값이 아니어서 검색이 제대로 적용되지 않았다. 이 수정은 검색 정확성과 요청량을 개선하지만 목록에 없는 종료 공고까지 생성하지는 않는다.
3. 안동 경로 추가: 기존 고시공고와 별개인 **유관기관 공지/소식**을 `andong_related`로 구성했다. `data-action` 상세 링크, POST 검색/페이지 이동, 목록 및 상세 작성일을 사용한다. 하이브레인 등록일을 원문 게시일로 대입하지 않는다.
4. 테스트 보완: TLS 오류 조합, HTTPS 리디렉션, 인증서 검증 유지, POST 전환, 날짜 오류 거부, CLI→DB→조회 및 중복 방지를 검증한다. 기존 속초 테스트도 POST 요청 본문을 검증하도록 변경했다.

운영 `config/config.toml`과 `data/judgefinder.db`는 수정하지 않았다. 속초 변경은 `config/batch-cafe-20261028.example.toml`, 새 안동 경로는 `config/batch-hibrain-recovery.example.toml`에 있다. 기존 운영 명령의 활성 소스에 안동이 자동 추가된 것은 아니다.

### 공통 원인 수정

1. 공개 JSON의 게시일이 밀리초 숫자라 기존 문자열 날짜 파서에서 거부되던 문제를 해결했다. `date_format = "unix_ms"`, `date_timezone = "Asia/Seoul"`을 명시한 경로만 숫자를 해석한다. 기존 문자열 날짜 처리의 기본값은 유지했다.
2. 해당 학회 화면과 동일하게 공개 게시일 `startDate`가 명시적으로 null일 때에만 설정한 등록 시각 `regDatetime`을 사용한다. 필드 자체가 없거나 잘못된 날짜라면 다른 날짜로 덮지 않고 오류 처리한다. 모집 기간이나 하이브레인 등록일은 대입하지 않는다.
3. 실제 사이트처럼 페이지 번호 없이 offset만 받는 HTML 목록을 지원했다. 불필요한 가짜 페이지 파라미터 없이 `per_page`를 이동하며 응답의 현재 페이지도 검증한다. 기존 일반 페이지·페이지+offset 방식은 유지한다.
4. ‘평가위원 공모 안내/알림’ 및 ‘평가위원 등록 안내’가 모집으로 분류되지 않던 누락을 보완했다. 결과·명단·취소·현황 안내와 등록 시스템 구축 입찰 등은 신규 규칙으로 모집 판정하지 않는다.

### 후속 검증

- 신규 경로 3개를 독립 HTTP 세션으로 두 번 실수집해 **7건의 기관명·제목·게시일·URL·종류가 일치**하는지 대조했다.

- 기존 안동 경로까지 포함한 실제 CLI `collect` 두 번과 `list`를 격리 DB로 실행했다. **8→8건**으로 중복이 없고 전체 필드가 일치했으며 `list`는 추가 HTTP 요청 없이 조회했다.
